Тренировочные ямы - здание в котором после забега генерируется случайное количество новых воинов, которых можно нанять.

Интерфейс окна состоит из двух частей
- Левая часть
	- Левый верхний угол - счётчик уровня здания
	- Декоративное изображение
	- Левый нижний угол - счётчик количества воинов в поселении.
- Правая часть
	- Список доступных к найму персонажей с кнопкой для просмотра листа каждого из персонажей чтобы увидеть характеристики. 
	- Кнопка "принять" для найма. Нанять можно если только в поселении есть доступные места
	- В самом низу под всеми персонажами находится кнопка для улучшения здания.
