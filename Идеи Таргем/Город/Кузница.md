# Описание

**Кузница** - это здание в котором игрок сможет **расплавлять** имеющееся снаряжение в ресурсы, а также из имеющихся ресурсов **ковать** снаряжение.

Интерфейс модульного окна состоит из следующих элементов:
- Левая часть
	- В верхнем правом углу располагается *счетчик* уровня здания
	- В верхнем правом углу располагается **кнопка** для улучшения здания и **текстом** с ценой улучшения
	- **Декоративное** изображение с кузней и наковальней, а также с ящиком на котором разложены инструменты.
- Правая часть
	- Верхняя половина содержит в себе *блок с кузней для расплавки снаряжения*:
		- В левой части:
			- **Декоративное** изображение кузни вблизи
			- **Слот** для снаряжения, если на него нажать то **откроется** модульное окно склада, в котором можно будет выбрать снаряжение. Если выбрать снаряжение то его *портрет* переместится в этот слот, а в правой части обновится текст.
		- В правой части:
			- **Текст** "Вы получите"
			- **Текст** "Осколки хитина" и **число** осколков хитина которые получит игрок при расплавке снаряжения
			- **Текст** "Кристаллы" и **число** кристаллов, которое получит игрок при расплавке снаряжения
			- **Кнопка** "Расплавить", которая удалит предмет из слота в кузне, но даст игроку указанное количество ресурсов. **Кнопка** будет доступна только если *в слоте указано снаряжение*.
	- Нижняя часть содержит в себе *блок с наковальней для ковки нового снаряжения*:
		- В левой части:
			- **Декоративное** изображение наковальни, вид сверху.
			- **Слот**, нажав на который мы можем выбрать из списка всего существующего снаряжения в игре нужное нам, а также эффект, который будет накладывать это снаряжение при атаке (эффект влияет на цену в кристаллах). Изображение расположено ниже.
		- В правой части:
			- **Текст** "Вы потратите"
			- **Текст** "Осколки хитина" и **число** осколков хитина, требуемых для ковки выбранного снаряжения
			- **Текст** "Кристаллы" и **число** кристаллов, требуемое для ковки выбранного снаряжения
			- **Кнопка** "Сковать", которая добавит скованный предмет на склад и **удалит** указанное количество ресурсов из счетчика ресурсов игрока. **Кнопка** будет доступна только в случае если **в слоте указано снаряжение** и при этом у Игрока **хватает ресурсов на ковку**

Интерфейс окна для выбора снаряжение на ковку состоит из двух частей
- Часть выбора вида снаряжения
	- Текст "Вид снаряжения"
	- Список в том или ином виде с возможными видами оружия
- Часть выбора эффекта
	- Текст "Эффект"
	- Список в том или ином виде с возможными эффектами на орудиях
