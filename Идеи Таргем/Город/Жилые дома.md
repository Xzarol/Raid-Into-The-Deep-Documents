# Описание
**Жилое здание** или **жилые дома** - здание, в котором можно узнать количество свободных мест в поселении, а также улучшить это здание для увеличения количества мест.

Интерфейс модульного окна состоит из следующих элементов:
- Левая часть
	- В верхнем левом углу располагается счётчик, указывающий текущее и максимальное количество жителей
