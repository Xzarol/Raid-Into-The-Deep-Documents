Атакующий, вспомогательный, для контроля

***По сути эффекты можно сократить до тех, которые только влияют на параметры.
Например "Мороз" - уменьшает скорость врага на n раундов
или "Ослабление" - уменьшает силу атаки врага на n раундов
И также можно усиливающие эффекты делать, например если хочешь использовать хилящее оружие то оно может заиметь эффект
"Усиление" - увеличивает силу атаки


***Снизу эффекты которые были придуманы ранее и возможно будут применены потом.

| Название                            | Описание                                                                                                                                                                  |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Яд оружие                           | наносит урон каждый ход                                                                                                                                                   |
| Оглушение оружие                    | оглушенный персонаж пропускает ход                                                                                                                                        |
| Лечение Расходник                   | выбранный персонаж лечит определенное количество здоровья                                                                                                                 |
| Дополнительное действие расходник   | выбранный персонаж может сделать два действия за ход                                                                                                                      |
| Щит расходник                       | следующий урон поглотится щитом, а щит исчезнет.                                                                                                                          |
| Сопротивление к оглушению расходник | появляется после оглушения, длится какое то количество раундов. Нужно чтобы игрок не мог оглушать постоянно.                                                              |
| Толкание оружие                     | Толкает персонажа от точки или к точке использования. Например если мы ударили врага то толкает врага от нас, если мы ударили притягивающим оружием то притягивает к нам. |
| Сон оружие                          | персонаж пропускает свои ходы пока по нему не нанесут урон или пока не пройдет определенное количество раундов                                                            |
| Огонь оружие                        | Персонаж получает урон от 1 до 4.                                                                                                                                         |
| Мороз оружие                        | Персонаж имеет половину скорости                                                                                                                                          |
| Ослабление оружие                   | Персонаж наносит на 10% меньше урона                                                                                                                                      |
| Усиление расходник                  | Персонаж наносит на 10% больше урона                                                                                                                                      |

Эффекты для навыков

| Название       | Описание                                                                                                                    | Длительность |     |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------ | --- |
| Боевой раж     | Находясь под этим эффектом, если персонаж убил врага то он делает дополнительный ход.                                       | 3 раунда     |     |
| Тяжелая рана   | Скорость персонажа уменьшается в половину с округлением вниз                                                                | 3 раунда     |     |

| Кровавая метка | Персонаж на которого наложили этот эффект получает урон равный характеристике того кто наложил эффект "Урон от эффектов" х2 | 3 раунда     |     |

Эффекты на клетках
Эти эффекты могут быть наложены прямо на клетки. В таком случае на клетке появляется отображение эффекта, например видимый пожар если наложен огонь.

| Название | Описание                                                                             | Отображение                                       |
| -------- | ------------------------------------------------------------------------------------ | ------------------------------------------------- |
| Огонь    | Длится 3 раунда. Если наступить на эту клетку, то на игрока наложится эффект "Огонь" | На клетке стоит огонь. Тут уже как удобней будет. |
| Яд       | Длится 3 раунда. Если наступить на клетку то на персонажа наложится эффект "Яд"      | На клетке стоит фиолетовое облако.                |
