
| Название                  | Описание                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Яд                        | наносит урон каждый ход                                                                                      |
| Оглушение                 | оглушенный персонаж пропускает ход                                                                           |
| Лечение                   | выбранный персонаж лечит определенное количество здоровья                                                    |
| Дополнительное действие   | выбранный персонаж может сделать два действия за ход                                                         |
| Щит                       | следующий урон поглотится щитом, а щит исчезнет.                                                             |
| Сопротивление к оглушению | появляется после оглушения, длится какое то количество раундов. Нужно чтобы игрок не мог оглушать постоянно. |
