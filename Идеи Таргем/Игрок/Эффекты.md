Атакующий, вспомогательный, для контроля

***По сути эффекты можно сократить до тех, которые только влияют на параметры.
Например "Мороз" - уменьшает скорость врага на n раундов
или "Ослабление" - уменьшает силу атаки врага на n раундов
И также можно усиливающие эффекты делать, например если хочешь использовать хилящее оружие то оно может заиметь эффект
"Усиление" - увеличивает силу атаки


***Снизу эффекты которые были придуманы ранее и возможно будут применены потом.

| Название                  | Описание                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Яд                        | наносит урон каждый ход                                                                                                                                                   |
| Оглушение                 | оглушенный персонаж пропускает ход                                                                                                                                        |
| Лечение                   | выбранный персонаж лечит определенное количество здоровья                                                                                                                 |
| Дополнительное действие   | выбранный персонаж может сделать два действия за ход                                                                                                                      |
| Щит                       | следующий урон поглотится щитом, а щит исчезнет.                                                                                                                          |
| Сопротивление к оглушению | появляется после оглушения, длится какое то количество раундов. Нужно чтобы игрок не мог оглушать постоянно.                                                              |
| Толкание                  | Толкает персонажа от точки или к точке использования. Например если мы ударили врага то толкает врага от нас, если мы ударили притягивающим оружием то притягивает к нам. |
| Сон                       | персонаж пропускает свои ходы пока по нему не нанесут урон или пока не пройдет определенное количество раундов                                                            |

Эффекты для навыков

| Название       | Описание                                                                                                                    | Длительность |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------ |
| Боевой раж     | Находясь под этим эффектом, если персонаж убил врага то он делает дополнительный ход.                                       | 3 раунда     |
| Тяжелая рана   | Скорость персонажа уменьшается в половину с округлением вниз                                                                | 3 раунда     |
| Защитник       | Если атакуют союзника в радиусе "Скорости" то персонаж получает урон вместо союзника                                        | 3 раунда     |
| Кровавая метка | Персонаж на которого наложили этот эффект получает урон равный характеристике того кто наложил эффект "Урон от эффектов" х2 | 3 раунда     |
| Обратный урон  | Атакующий персонажа с этим эффектом получает обратно половину нанесенного урона                                             | 3 раунда     |
