Атакующий, вспомогательный, для контроля
По сути эффекты могут быть:
- Воздействующие на параметры
- Дающие 

| Название                  | Описание                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Яд                        | наносит урон каждый ход                                                                                                                                                   |
| Оглушение                 | оглушенный персонаж пропускает ход                                                                                                                                        |
| Лечение                   | выбранный персонаж лечит определенное количество здоровья                                                                                                                 |
| Дополнительное действие   | выбранный персонаж может сделать два действия за ход                                                                                                                      |
| Щит                       | следующий урон поглотится щитом, а щит исчезнет.                                                                                                                          |
| Сопротивление к оглушению | появляется после оглушения, длится какое то количество раундов. Нужно чтобы игрок не мог оглушать постоянно.                                                              |
| Толкание                  | Толкает персонажа от точки или к точке использования. Например если мы ударили врага то толкает врага от нас, если мы ударили притягивающим оружием то притягивает к нам. |
| Сон                       | персонаж пропускает свои ходы пока по нему не нанесут урон или пока не пройдет определенное количество раундов                                                            |
